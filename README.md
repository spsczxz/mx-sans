# mx-sans
a repository of metrolinx's private fonts used across their website, postage, and public material.

### why?
because fonts are cool, and someone was asking.

### how to install?
windows: clone the repo > extract > select all 4 fonts > (windows 11: shift) + right click > install.

mac: drag and drop all 4 into the "font book" app, or double tap + install.

## legal
this is not my font, it belongs to metrolinx. use wisely.
